#### Featured project

**[Kairos](https://github.com/ardaege159/kairos)**: a personal research terminal for ~12,000 US stocks and ETFs, built on free public data (SEC EDGAR, Alpaca, FRED, USAspending, 13F filings).
- A transparent 0–100 score and a rule-based bull/bear outlook. Every number is computed in code.
- LLM layer: Turkish stock summaries that may only restate the computed facts, and opinion extraction from investment blogs, with each ticker checked against the company name to catch hallucinated symbols.
- Next.js 16, TypeScript, Supabase (Postgres + RLS), Vercel, GitHub Actions data pipelines, 96 unit tests.
